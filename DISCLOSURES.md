# DISCLOSURES.md

## AI assistance

This project was built with an AI coding assistant (a large language model agent run in the terminal) under the direction of the repository owner. The owner reviewed and directed the work and approved the commits, which are authored by the owner only. Models inside the product are NVIDIA Nemotron, served through the NVIDIA API Catalog (development route) and, when a key exists, Nebius Token Factory.

## Data

- The profile of Arjun Menon and every document, contract and ledger entry shown is a specimen profile created for the demonstration. Specimen certificates are labelled SPECIMEN.
- Synthetic seafarer profiles and synthetic identifier values in `eval/` are labelled SYNTHETIC.
- No real identifier, certificate image or personal document is committed.

## Email delivery

Packets are sent through Resend. A Resend account without a verified sending domain can deliver only to the address it was created with, so the "manning agent" inbox in the live flow is the owner's own Resend sign-up address, and the sender is `onboarding@resend.dev`. No real manning agent receives anything from this project. Gmail SMTP is not used.

## Sources read through a third party

The India DG Shipping and Singapore MPA hosts refuse connections from the build network, so those documents were read through Tavily Extract, which fetches from Tavily's servers. Each rule records the URL actually read and the date.
