## Track (ours): Personal AI

Build an always-on, private assistant that works for you while keeping your data under your control. Give it persistent memory, reusable skills, access to the tools and information you choose, and the ability to carry out tasks across your daily workflows. Use at least one NVIDIA open source model, and use tools such as NVIDIA NemoClaw, OpenShell, Hermes Agent, and Nebius Serverless to bring personal AI to assemble, secure, and run your own personal AI system.

Other tracks: Coding and Agentic Engineering, Best Apps and Agents, Physical AI.

## Judging criteria (four, equal weight)

1. Technological Implementation: how well built; how effectively it uses Token Factory or AI Cloud models and NVIDIA Nemotron.
2. Design: a complete, coherent product experience, not a proof of concept.
3. Potential Impact: a credible, specific case for a real problem and a real audience, addressed in what is demonstrated.
4. Quality of the Idea: creative, non-obvious use of Token Factory or AI Cloud models and Nemotron, with genuine understanding of the problem space.

Ties break on the first criterion in the list above.

## Prizes

Grand $20,000; 2nd $10,000; 3rd $6,000; each track winner: one NVIDIA Jetson Orin Nano; Best Use of Tavily $3,000; City Winner Awards $500 x 20 (only for in-person Builders and Brews attendees; not applicable); Most Valuable Feedback $100 x 10; NVIDIA swag pack.

## Required items

- A working project that makes a runtime call to the Token Factory inference API, or runs on Nebius AI Cloud compute, and uses at least one NVIDIA open source model.
- A track.
- A text description of features and functionality.
- A working demo URL, free to use and without restriction until judging ends. If private, credentials must be in the testing instructions.
- A public repository (GitHub, GitLab or Bitbucket) with an open source licence visible in the About section, all source and assets, and a README with setup and run instructions.
- The README must highlight how Nemotron or other NVIDIA open source models were used, where Token Factory accelerated the workflow, and any other Nebius tools used.
- Feedback on Token Factory, AI Cloud and any NVIDIA tools used.
- A statement of what was significantly updated, if the project existed before the submission period (Dogwatch is new in the period).
- A demo video.

## Video rules

- Under three minutes; judges are not required to watch beyond three.
- Public on YouTube, link on the submission form.
- Shows the project functioning on the device it was built for.
- No third-party trademarks and no copyrighted music or other material without permission.

## Other rules that shape the build

- Third-party SDKs, APIs and data must be used within their terms.
- Judges may judge from the description, images and video alone.
- Builder Program credits (Token Factory, Tavily, Nebius Academy) are available through the Nebius Builder Program.
- Submissions are the entrant's original work, solely owned, not violating others' IP.
